# Geolocation-Tracker
## Description

This Python application fetches the user's current location using their public IP address and displays it on an interactive map.

---

## Features

- Detects Public IP Address
- Finds City
- Finds State
- Finds Country
- Displays Latitude & Longitude
- Shows ISP Information
- Opens Interactive Map in Browser

---

## Technologies Used

- Python
- Requests
- Folium

---

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

---

## Run the Project

```bash
python app.py
```

---

## Output

The application displays:

- IP Address
- City
- State
- Country
- Latitude
- Longitude
- Timezone
- ISP

It also generates:

```
location.html
```

which opens in your browser with a marker showing your location.
